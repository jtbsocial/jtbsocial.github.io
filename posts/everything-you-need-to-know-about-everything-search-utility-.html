What is Voidtools Everything?

Created by developer David Carpenter under Voidtools, Everything is a lightweight administrative desktop search engine for Microsoft Windows. Unlike traditional desktop indexers that read every file line-by-line to build search catalogs, Everything interfaces directly with the low-level Master File Table (MFT) of NTFS formatted drives.

By monitoring the MFT change journal directly from the kernel level, Everything indexes fresh Windows installations containing over 1,000,000 files in under 2 seconds. When you open the utility, every file and folder on your local drives appears instantly, updating in real time as files are created, renamed, moved, or deleted.

How It Works Under the Hood

  1. Direct MFT Parsing: Reads raw file system structure metadata directly from NTFS volumes rather than traversing directory trees.
  2. ReFS and FAT/exFAT Support: Uses background directory monitoring for non-NTFS partitions and network attached storage (NAS) devices.
  3. USN Journal Monitoring: Tracks Update Sequence Number (USN) logs to keep the index 100% current without rescanning disks.
  4. In-Memory Querying: Holds file path pointers in system memory for microsecond query response rates.
