If you have ever typed a file name into the native Windows Explorer search bar only to watch a green loading bar crawl sluggishly across the address bar while your CPU fans ramp up to turbine levels, you are not alone. Native Windows Search has long suffered from heavy index database bloating, sluggish query responses, and missed file results due to restrictive library indexing defaults.

Enter Everything, the lightweight, freeware desktop search utility created by David Carpenter of voidtools. Designed to replace sluggish native file indexing, Everything delivers near-instantaneous search responses across millions of files on local drives and network shares. Whether you are managing multi-terabyte media arrays, massive code bases, or thousands of office documents, Everything turns searching into an instantaneous impulse rather than a tedious waiting game.

What is Voidtools Everything?

Everything is an administrative desktop search utility built exclusively for Microsoft Windows (supporting Windows 7, 8, 10, 11, and Server editions in both 32-bit and 64-bit architectures). Unlike heavy search indexers that analyze document text frame by frame upon system boot, Everything focuses primarily on file names and directory structures.

When launched for the first time, Everything indexes a fresh installation of Windows—containing roughly 1,000,000 files—in approximately 1 second. As you type characters into its minimal interface, search results update dynamically in real time without lag.

Key Core Capabilities:

  • Small executable file size (less than 5 MB total installation size).
  • Clean, non-intrusive user interface with customizable columns.
  • Real-time monitoring of file system changes.
  • Real-time search updating as you type.
  • Low system memory footprint (~15-30 MB RAM idle).
  • Easy file sharing via built-in HTTP and FTP web servers.

Under the Hood: How Everything Achieves Lightning Speeds

How can Everything return search results in milliseconds while Windows Explorer takes minutes? The secret lies in its clever low-level file system interaction.

The NTFS Master File Table (MFT)

On NTFS-formatted drives, the operating system maintains a hidden structural database called the Master File Table (MFT). The MFT acts as an index catalog containing metadata for every file and folder stored on the volume—including name, creation date, modification timestamp, permissions, and cluster locations.

Rather than crawling every folder branch sequentially on your hard drive, Everything requests direct read access to the NTFS MFT directly through Windows storage APIs. It parses this pre-existing structural database into memory instantly upon startup.

When a file is created, deleted, or renamed, Windows posts an update event to the NTFS USN Change Journal (Update Sequence Number Journal). Everything monitors this change journal continuously in the background, updating its internal RAM index instantly with negligible CPU usage.

Everything 1.4 Stable vs. Everything 1.5 Beta: Key Differences

While Everything 1.4.1.1032 remains the rock-solid official stable release, voidtools has made enormous strides with the Everything 1.5.0 Alpha/Beta release cycle. Version 1.5 expands the utility from a pure filename indexer into a fully customisable data management engine.

Major Additions in Everything 1.5:

  1. Property Indexing: Index EXIF metadata (camera model, ISO), audio metadata (ID3 tags, bitrate), video dimensions, document authors, and file checksums (MD5/SHA-256).
  2. Fast Content Searching: Ability to perform indexed content searches inside plain text, source code, PDFs, and Office documents.
  3. Native Dark Mode: Full UI skinning supporting native Windows 11 system accent themes and dark palettes.
  4. Improved Multi-Threading: Sub-millisecond sorting of millions of entries across multi-core CPUs.
  5. Trash & Recycle Bin Indexing: Search items currently sitting in the Recycle Bin before permanent deletion.
