What is Everything by voidtools?

Created by David Carpenter under the banner of voidtools, Everything is a freeware administrative desktop search engine designed specifically for Microsoft Windows. Unlike built-in OS utilities that build sluggish, resource-heavy indexes of file contents, Everything focuses primarily on file and folder name indexing.

When launched for the first time on a fresh Windows installation containing over 1,000,000 files, Everything creates its search database in roughly 1 to 2 seconds. Once indexed, search results update live on every keystroke, delivering a truly real-time search experience that leaves native Windows Search in the dust.

How Everything Achieves Near-Instant Search Speed

To understand why Everything feels like black magic, it helps to look under the hood at how Microsoft Windows stores data.

The Magic of NTFS MFT and USN Journal

Traditional search tools crawl every directory on your storage drive, opening folders sequentially to catalog files—a process that takes minutes or even hours on large hard drives. Everything bypasses this bottleneck entirely:

  1. Direct MFT Parsing: Everything reads the Master File Table (MFT) of NTFS formatted volumes directly at low hardware levels.
  2. USN Change Journal Tracking: Instead of continually re-scanning drives for changes, Everything monitors the Update Sequence Number (USN) Change Journal. The moment a file is created, renamed, modified, or deleted, Windows logs it in the USN journal, and Everything updates its index in real time.
  3. In-Memory Sorting: The entire file index is loaded directly into RAM, enabling instant filtering as you type.

Core Features & Power-User Capabilities

Everything is far more than a basic search bar. It includes deep system integration tools designed for administrators, data managers, and power users.

1. Minimalist Interface & Instant Live Filters

The UI is uncluttered and clean. Filter bars allow you to instantly limit your queries to specific categories such as Audio, Compressed, Document, Executable, Folder, Image, or Video with a single click.

2. Built-in HTTP and FTP Server

Need to fetch a file located on your desktop PC while working on your laptop across the house? Everything contains an embedded lightweight HTTP and FTP server. When enabled, you can open any web browser on your local network, type in your PC's IP address, search your entire hard drive remotely, and download files instantly.

3. Comprehensive File Operations & Mass Rename

Selecting multiple files within Everything allows you to invoke powerful context menu commands. The Advanced Change Name tool lets users batch-rename hundreds of files using regular expression pattern matching and sequence numbering.
