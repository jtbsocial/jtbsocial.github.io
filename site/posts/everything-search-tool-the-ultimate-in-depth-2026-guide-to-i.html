What is voidtools Everything?

Developed by David Carpenter of voidtools, Everything is an elite desktop file search engine designed exclusively for Windows. While traditional search utilities inspect every file's meta tags and contents line-by-line, Everything focuses purely on indexing filenames, folder structures, timestamps, and file sizes.

Because it does not force full-text content indexing by default, Everything achieves speeds that feel almost magical. The Engineering Magic: How Everything Searches Millions of Files Instantly

To understand why Everything leaves default operating system utilities in the dust, one must look under the hood at Windows storage architecture.

1. Direct NTFS Master File Table (MFT) Reading

When installed with administrative rights, Everything bypasses standard Windows File System APIs. Instead, it directly reads the Master File Table (MFT)—a hidden system file on NTFS partitions that tracks every file and directory attribute stored on disk. By directly reading binary record streams straight from the drive controller, Everything avoids disk seek delays.

2. Monitoring the USN Change Journal

Once the initial MFT scan is loaded into memory, Everything doesn't re-scan your hard drives. Instead, it hooks into the NTFS Update Sequence Number (USN) Change Journal. Whenever a file is created, deleted, renamed, or modified, Windows logs the event in the USN journal. Everything reads this live stream continuously, updating its memory database instantly while consuming near-zero system resources.

3. Non-NTFS Drives & ReFS Support

For non-NTFS storage (such as FAT32, exFAT, network NAS shares, or ReFS drives), Everything utilizes folder indexing services and scheduled background polling to maintain up-to-date file lists across your entire storage architecture.

Masterclass: Advanced Search Operators, Filters & Regex

While Everything works straight out of the box with standard text queries, its true power unlocks when leveraging special search syntax and operators.

Essential Search Operators

  • Space as AND Operator: report 2026 finds all files containing both "report" and "2026".
  • OR Operator (|): png|jpg finds files with either png or jpg in their filename.
  • NOT Operator (!): !draft presentation finds files containing "presentation" but excluding "draft".
  • Wildcards (* and ?):
  • *.docx lists all Microsoft Word documents.
  • video_??? .mp4 finds files like video_001.mp4 or video_abc.mp4.

Advanced Search Modifiers

# Find files larger than 1 Gigabyte created in the last 7 days
size:>1gb dm:last7days

# Search strictly within a specific folder directory for audio files
"C:\Projects\Audio" ext:wav;flac;mp3

# Find empty folders across drive D:
D: folder: empty:

# Find duplicate files based on name and size
dup: size:>100mb

Regular Expressions (Regex) Cheat Sheet

By pressing Ctrl + R or enabling Match Regex under the Search menu, you can unleash advanced pattern matching:

  • ^ - Matches start of filename (e.g., ^Backup matches files starting with Backup).
  • $ - Matches end of filename (e.g., final$ matches names ending with final).
  • [0-9]{4} - Matches any 4-digit sequence (e.g., finding year stamps like 2026).

Server Plugin & Network Indexing Deep-Dive

One of the most powerful yet underutilized capabilities of Everything is its built-in networking suite. It can act as a lightweight network server to share file directory access across local intranets or remote workgroups.

1. Everything HTTP Server

By navigating to Tools -> Options -> HTTP Server, users can enable an embedded web server on a custom port (e.g., 8080). Network administrators can search, view, and download files stored on a remote desktop server straight from any modern desktop or mobile browser without configuring heavy SAMBA/SMB shares.

2. Everything FTP Server

For secure file transfer pipelines, Everything includes an integrated FTP service (Tools -> Options -> FTP Server). Users can connect via FileZilla or script automated automated backup pipelines that query storage nodes in real time.

3. ETP/FTP Indexing for Multi-Client Synchronization

In enterprise environment topologies, multiple Everything clients can connect to a central Everything ETP Server. This allows remote workstations to search multi-terabyte corporate file servers instantly without needing local administrator rights or heavy disk scans.

Frequently Asked Questions (FAQs)

1. What is voidtools Everything search utility?

Everything is a free, lightweight desktop search tool for Windows that indexes file and folder names instantly using direct NTFS Master File Table parsing and real-time USN change logs.

2. Is Everything search software safe and free to use?

Yes, Everything is completely safe, clean, and free for both personal and commercial use. It contains no adware, spyware, bundleware, or user tracking telemetry.

3. How does Everything search so much faster than native Windows Search?

Instead of opening every file and scanning its inner metadata line-by-line, Everything reads the binary NTFS Master File Table (MFT) directly from the storage drive controller, allowing it to build an index of millions of files in less than a second.

4. Can Everything index network drives, NAS, or external USB storage?

Yes. While internal NTFS drives are indexed instantly via MFT logs, external USB drives (exFAT/FAT32) and network NAS drives can be added under Tools -> Options -> Folders to be indexed via scheduled background polling.

5. What are the most useful keyboard shortcuts in Everything?

Pressing Ctrl + F focuses the search bar, Ctrl + R toggles Regular Expressions (Regex), Ctrl + Shift + C copies the selected file path to your clipboard, and Alt + Enter opens the native Windows file properties dialog.
