What Is Everything by Voidtools?

Created by developer David Carpenter under the banner of Voidtools, Everything is a lightweight freeware search utility designed specifically for Microsoft Windows (supporting Windows 7, 10, 11, and Windows Server editions). Unlike native Windows Search, which reads file contents and creates massive index databases that devour gigabytes of storage, Everything focuses exclusively on locate files and folders by name instantly.

When launched, Everything reads the USN (Update Sequence Number) Change Journal and MFT directly from your formatted NTFS drives. Because it only tracks metadata related to filenames and paths rather than deep document contents, its index database remains astonishingly small (typically 3 to 5 megabytes for 500,000 files).

Key Features of Voidtools Everything in 2026

1. Instant Real-Time Indexing and USN Journal Tracking

Whenever a file is created, renamed, moved, or deleted anywhere on your storage volumes, Windows updates its NTFS Change Journal. Everything monitors this low-level log in real-time. As a result, search queries update instantly dynamic as you type without requiring manual re-indexing or periodic scans.

2. Built-in HTTP and FTP Server Plugins

Everything isn't confined to a local desktop view. Through the built-in HTTP server, you can host your local index on a local network or VPN. This allows you to search, view, and securely download files stored on your home server or desktop PC directly from a web browser on a smartphone, tablet, or secondary laptop.

3. Command-Line Interface (CLI) & SDK Integration

For developers and system automation scripts, Voidtools provides a robust Command-Line Interface (es.exe) and an SDK (DLL). You can query file locations inside PowerShell scripts, batch automation pipelines, or third-party launchers such as PowerToys Run, Alfred alternatives, or Flow Launcher.

4. Custom Filters and Bookmarks

Users can build specialized search presets. For example, creating a filter named Large Videos configured to ext:mp4;mkv;avi size:>2gb allows you to instantly isolate storage-hogging media with a single click or keyboard shortcut.

Deep Dive: Mastering Everything Search Syntax & Regex

While simple keyword typing returns rapid results, unlocking the true power of Voidtools Everything requires understanding search syntax operators.

Basic Search Modifiers & Wildcards

  • * Matches zero or more characters (e.g., report*.pdf).
  • ? Matches exactly one character (e.g., img_202?.jpg).
  • " " Exact phrase matching (e.g., "Quarterly Financial Report").
  • | Logical OR operator (e.g., png | jpg | webp).
  • ! Logical NOT operator (e.g., draft !final).

Regular Expressions (Regex) Support

By toggling Regex mode (Ctrl + R or using the regex: prefix), power users can execute precise pattern matching across vast disk structures:

  • regex:^[0-9]{4}_log : Finds files starting with a 4-digit year followed by _log.
  • regex:[A-Z0-9._%+-]+@[A-Z0-9.-]+\.[A-Z]{2,} : Finds files containing standardized email string patterns in their titles.

How to Install & Configure Everything for Peak Performance

Follow this step-by-step installation blueprint to ensure seamless operation without triggering unnecessary administrative prompts:

Step 1: Download Official Binaries

Always download Everything directly from the official voidtools portal (voidtools.com) or verified package managers (winget install voidtools.Everything). Choose between the standard 64-bit installer or portable ZIP build.

Step 2: Configure Service Elevation

During installation, select Install Everything Service.

💡 Pro Tip: Running the Everything Service allows the main user interface to access low-level NTFS indexing without requiring Windows Administrator Privileges (UAC prompts) every time the app launches on startup.

Step 3: Set Up Hotkeys for Instant Access

  1. Open Everything, navigate to Tools > Options > Keyboard.
  2. Locate Show Window Hotkey.
  3. Assign a universal shortcut such as Alt + Space or Ctrl + Shift + F.
  4. Now, pressing your hotkey opens a clean, instant search bar anywhere in Windows.

Step 4: Indexing Network Volumes (NAS)

While NTFS local drives index automatically, network attached storage (NAS) formatted in SMB/CIFS requires explicit indexing:
1. Go to Tools > Options > Indexes > Folders.
2. Click Add and enter your UNC network path (e.g., \\NAS\Storage\Documents).
3. Set rescan intervals or enable folder change monitoring.

Voidtools Everything vs. Native Windows 11 Search

Why does Microsoft native search continue to struggle while Voidtools delivers instantaneous results?

Voidtools:       [MFT Memory Reader]     -> [Filename Index]   -> [Zero Disk I/O] -> [Instant Results]
  1. Approach Difference: Windows Search attempts to parse the full text content inside Word documents, PDFs, and code repositories. This causes continuous hard drive thrashing and high background CPU usage. Everything focuses on fast file name locating.
  2. Database Integrity: Windows Search indexes frequently corrupt or stall after major Windows Updates, forcing multi-hour index rebuilds. Everything rebuilds its index in under two seconds upon app launch.
  3. Interface Simplicity: Everything provides an unbloated UI free of Bing web search integration, start menu advertisements, or unwanted widget recommendations.
