Created by David Carpenter of Voidtools, Everything is a lightweight desktop search utility designed exclusively for Microsoft Windows operating systems. Unlike default OS tools that spend hours indexing every character within thousands of documents, Everything focuses primarily on indexing file names and folder structures at lightning speeds.

When launched for the first time on a fresh drive, Everything builds a full index of your local NTFS storage volumes almost instantaneously. Because it interacts directly with low-level disk systems rather than scanning directories folder-by-folder, searches update live as you type each keystroke.

How It Works: The NTFS USN Journal Advantage

The secret to Everything's unbelievable speed lies in how it interacts with the NTFS file system. Microsoft Windows uses the Master File Table (MFT) and Update Sequence Number (USN) Change Journal to record changes made to files and directories on NTFS volumes.

Instead of recursively browsing through every directory on your storage drive—which causes high disk usage and thermal throttling—Everything requests read access to the USN Change Journal directly. It parses this raw structural record into an optimized in-memory database. Whenever a file is created, renamed, or deleted anywhere on your system, the USN journal broadcasts the change, and Everything updates its search index instantly.

Key Features Breakdown

1. Minimal System Resource Usage

Standard desktop search tools often run background indexer services that spin up disk reads right when you are playing a game or rendering a video. Everything requires minimal system resources:
* A clean installation uses approximately 14 MB of RAM for 100,000 files.
* Disk space consumption for the database index is roughly 3 MB to 5 MB per 100,000 files.
* Zero active background processing occurs when queries are inactive.

2. Live Instant Searching & Custom Filters

As you type into the search bar, results filter live in real time. You can restrict searches to specific file types with single-click filters like Audio, Executable, Archive, Document, Picture, or Video.

3. Server Plugin & ETP/FTP Remote Search

Everything can run as an HTTP or ETP/FTP server, allowing you to search files on remote workstations, server racks, or NAS units across your local area network (LAN) or virtual private network (VPN) securely.

4. Command-Line Interface (CLI)

For developers and automation engineers, the optional Command-Line Interface (es.exe) enables command-prompt integration. You can pipe search results directly into PowerShell scripts, batch automation workflows, or system backup utilities.

Master Search Syntax & Cheat Sheet

Unlocking the full power of Everything comes down to knowing its intuitive search syntax. Here is a reference table of the most useful search operators:

Search Query Example Description / Function
report .pdf Finds files containing both "report" and ".pdf" anywhere in their name
"annual summary" Searches for the exact phrase "annual summary"
spec|sheet Finds files containing either "spec" OR "sheet"
!temp Excludes any file or folder containing the word "temp"
ext:png;jpg;gif Displays only image files with png, jpg, or gif extensions
size:>1gb Displays files larger than 1 Gigabyte
datecreated:today Lists files created on the current date
path:d:\projects Restricts search strictly to the D:\projects directory
dupe: Identifies duplicate file names across indexed drives
empty: Locates empty folders or zero-byte files

Advanced Regex (Regular Expressions) Examples

By toggling Search -> Enable Regex (or using regex: syntax), you can run complex pattern matching:
* regex:^[0-9]{4}- : Finds files starting with a 4-digit year followed by a hyphen (e.g., 2026-invoice.pdf).
* regex:(backup|archive) : Matches exact whole words "backup" or "archive".

Installation and Optimal Configuration Guide

Getting started with Everything takes under two minutes. Follow this step-by-step installation guide to set up your environment optimally.

+-------------------------------------------------------------------------+
|                    OPTIMAL INSTALLATION WORKFLOW                         |
+-------------------------------------------------------------------------+
|  1. Download Installer  --> 2. Select Everything Service  --> 3. Configure |
|  (64-bit / ARM64 build)     (Runs without Admin prompts)   Quick Keys   |
+-------------------------------------------------------------------------+

Step 1: Downloading the Right Package

Visit the official Voidtools website (voidtools.com) and select the package matching your operating system:
* Everything Installer (64-bit / ARM64): Recommended for standard installations.
* Portable Version: Zip file requiring no installation—ideal for running off USB drives.
* Everything Server Plugin: Adds advanced network-wide server indexing capabilities.
* Command-line Interface (ES): Download es.exe for console automation.

Step 2: Privilege Setup (Service vs. Admin Mode)

During installation, you will be prompted to select how Everything accesses your disk journals:
1. Install Everything Service (Recommended): Runs a silent background service with system privileges to read the USN journal. The GUI client runs standard user permissions, avoiding UAC administrator prompts every time you launch it.
2. Run as Administrator: Requires granting administrative rights on launch. Not recommended for multi-user shared machines.

Step 3: Setting Up Global Hotkeys

To make search instant from anywhere in Windows:
1. Open Everything and navigate to Tools -> Options.
2. Select Keyboard under the General side menu.
3. Click on Toggle Hotkey and set a shortcut (e.g., Alt + Space or Ctrl + Shift + F).
4. Click Apply.
Now, pressing your hotkey instantly pops up the Everything search bar from any app.

FAQs: High-Intent Questions Answered

1. What makes Voidtools Everything so much faster than built-in Windows Search?

Voidtools Everything bypasses traditional file-by-file system traversal by reading the NTFS Master File Table (MFT) and USN Change Journal directly. Rather than reading the contents of every file, it indexes raw name and path data directly from the system storage journal, completing queries in milliseconds.

2. Is Voidtools Everything completely free for commercial and personal use?

Yes. Voidtools Everything is 100% freeware for both personal and commercial use. There are no hidden subscription fees, lockouts, or bundled adware. Voluntary donations can be made directly to the developer via the official Voidtools website.

3. How much system RAM and storage space does Everything consume?

Everything is extremely lightweight. An index containing 100,000 files consumes roughly 14 MB of RAM and under 5 MB of storage space for its database file. Even setups indexing 2 million files rarely exceed 150 MB of RAM usage.

4. How do I enable the Everything Server Plugin for remote file searching?

Open Everything, navigate to Tools -> Options -> HTTP Server (or ETP/FTP Server), check Enable HTTP Server, set your designated port (e.g., 80 or 8080), and set authentication credentials. Remote devices can then search your indexed files securely using any modern web browser across your local network.

5. Can Everything index non-NTFS drives like FAT32, exFAT, or network shares?

Yes. While NTFS volumes index instantly via USN journals, non-NTFS drives (such as FAT32, exFAT, USB thumb drives, or mapped network NAS shares) can be added under Tools -> Options -> Indexes -> Folders. Everything monitors these folders using standard directory notifications.
