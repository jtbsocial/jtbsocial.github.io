Created by voidtools, Everything is a freeware administrative desktop search utility designed for Microsoft Windows. Unlike traditional desktop search tools that crawl the file system line-by-line and build massive database indexes containing text content, Everything focuses strictly on file and folder names.

By bypassing full-text content indexing and focusing directly on file system metadata, Everything achieves unparalleled search speeds. When you open Everything and type a filename, results update dynamically with every single keystroke.

  4. Remote Access: Built-in HTTP and FTP servers allow searching local files across a local network.
  5. Command-Line Interface (CLI): Seamless integration into scripts, batch files, and automated workflows.

How Everything Achieves Sub-Second Searches

How can Everything query 2,000,000 files in less than 0.05 seconds while native Windows Search takes several minutes?

1. Direct NTFS Master File Table (MFT) Reading

When installed on an NTFS volume, Everything requests administrative privileges to read the volume's Master File Table (MFT) directly. The MFT is a special database stored by NTFS that contains raw metadata for every file and directory on the partition. Instead of traversing folders recursively, Everything reads this database sequentially into memory during initialization.

2. Low-Overhead Memory Database

Everything constructs a streamlined, highly optimized in-memory index consisting solely of file paths, names, and timestamps. A typical system with 1,000,000 files requires roughly 20 MB to 40 MB of RAM to maintain this index in memory.

3. USN Journal Monitoring

To keep search results completely accurate without constantly re-scanning disks, Everything connects to the NTFS Update Sequence Number (USN) Change Journal. Whenever a file is modified, created, or deleted, Windows logs the change in the USN Journal. Everything listens to this stream in real time, updating its internal index instantly without triggering heavy disk I/O.

Key Components & Advanced Features

1. The Command-Line Interface (CLI)

For system administrators and DevOps engineers, voidtools provides a dedicated Everything Command-line Interface (es.exe). This command-line utility lets users execute queries directly from PowerShell, Command Prompt, or automation scripts.

:: Example CLI Command to search for .log files modified today
es.exe *.log dm:today -sort date-modified-desc

2. Everything Server Plugin & Remote Indexing

Everything features an HTTP and FTP server plugin module. When enabled, users can host their file index over a local network (LAN) or secure VPN. Authorized devices can open a browser, navigate to the host's IP address, and search shared network storage through a clean web portal without requiring local file share mounts.

3. Language Packs & Global Support

Through the official voidtools Language Pack, Everything supports over 40 languages, enabling seamless global deployment across enterprise infrastructure.

4. The 2026 Open-Source Horizon: HeyPuter's Everything Project

In recent years, developer communities have taken inspiration from voidtools to rethink desktop operating systems entirely. Open-source initiatives like HeyPuter/everything aim to rebuild desktop software environments from scratch, blending desktop-level file management directly into cloud and browser ecosystems. While voidtools remains the undisputed king of local Windows file indexing, these open-source developments highlight the industry-wide demand for high-speed, zero-bloat file management.
